# Reestar Website

## 📌 About the Project

Reestar is a simple food-themed website created using HTML5 and CSS3. The website showcases food items in an attractive and organized layout. 
This project helped me practice HTML page structure, CSS styling, spacing, and layout design while improving my front-end development skills.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Clean and simple user interface
* Food item display section
* Styled content using CSS
* Organized layout and spacing
* Beginner-friendly front-end design

## 🎯 Purpose

The main purpose of this project is to strengthen my HTML and CSS fundamentals and gain practical experience in building websites from scratch.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in your web browser.
